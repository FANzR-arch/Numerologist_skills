# 六爻取用神

先按所问之事取用神（六亲），再看用神在卦中的旺衰、动静、空破与生克。下表为常见取法，问事不在表内时按"所问之人或物与问卦者的关系"类推。

> 出处：《增刪卜易》第八章「用神章」（各六亲所主）；第三章「八宫图」后文「自占吉凶者以世爻为用神」。表中「证件、消息、娱乐、女友、男友、病症、上司、工作职位」是现代引申或未核对条目，向用户说明。应爻作对方一行未核对。

| 所问 | 用神 |
|---|---|
| 父母长辈、师长、房屋车辆、文书合同、证件、考试文章、消息 | 父母 |
| 兄弟姐妹、朋友同辈、竞争者；问财时为劫财之神 | 兄弟 |
| 子女晚辈、学生、医药医生、宠物、娱乐；问官时为伤官之神 | 子孙 |
| 钱财、收入、货物、妻子（男问）、女友（男问）、仆从 | 妻财 |
| 工作职位、官司、上司、丈夫（女问）、男友（女问）、病症、灾祸、盗贼 | 官鬼 |
| 自己（问自身吉凶、运势） | 世爻 |
| 对方、对手、所去之处、所托之人 | 应爻 |

## 原神、忌神、仇神

> 出处：《增刪卜易》第九章「用神元神忌神仇神章」（书中称「元神」）；第十章「元神忌神衰旺章」。

以用神五行为准：

- 原神：生用神者。原神旺动，用神得助。
- 忌神：克用神者。忌神旺动，用神受伤。
- 仇神：生忌神、克原神者。

## 断卦常看

> 出处：1 见《增刪卜易》第二十八章「飞伏神章」；3 见第七章「动变章」、第十章（动化回头生）；4 见第二十六章「旬空章」（出空之日应事）。2 的月建日辰、5 的世应生克未逐句核对。

1. 用神是否上卦；不上卦看伏神及其飞神生克。
2. 用神旺衰：得月建、日辰生扶为旺；被月建、日辰克为衰。
3. 动静：动爻能生克他爻；变爻回头生为得助，回头克为受制。
4. 空破：旬空、月破之爻一时无力，出空、填实之日为应期参考。
5. 世应关系：世应相生相合多顺，相冲相克多阻。
